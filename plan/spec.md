# 社員情報管理アプリ 仕様まとめ

## 1. コア機能

| 機能                 | 概要                                                       |
| -------------------- | ---------------------------------------------------------- |
| 社員アカウント登録   | admin ユーザーが社員アカウントを登録する                   |
| ログイン・ログアウト | admin が登録したアカウントでログイン。パスワード変更も可能 |
| 社員情報編集         | ログイン中の本人が自分の情報を編集できる                   |
| 勤怠管理             | 社員が自分の勤怠時間を入力・管理できる（月次集計型）       |
| 社員アカウント管理   | admin のみ利用可能。権限変更・アカウント削除               |

---

## 2. ユーザー権限

| 権限     | 閲覧           | 自分の情報編集 | 自分の勤怠 | 全員の勤怠 | アカウント管理 |
| -------- | -------------- | -------------- | ---------- | ---------- | -------------- |
| 未登録   | ✗ ログイン必須 | ✗              | ✗          | ✗          | ✗              |
| 一般社員 | ✓ 自分のみ     | ✓              | ✓          | ✗          | ✗              |
| admin    | ✓ 自分のみ     | ✓              | ✓          | ✓ 全員分   | ✓              |

---

## 3. 社員情報項目

- 氏名
- 部署
- 役職
- メールアドレス
- 電話番号
- 入社日

---

## 4. 勤怠管理

| 項目     | 内容                             |
| -------- | -------------------------------- |
| 入力方式 | 出勤・退勤時刻を日ごとに手入力   |
| 集計     | 月の合計時間を表示（月次集計型） |
| 一般社員 | 自分の勤怠のみ操作・閲覧可能     |
| admin    | 全員分の勤怠を閲覧可能           |

---

## 5. admin 設計

| 項目           | 決定内容                             |
| -------------- | ------------------------------------ |
| 初期 admin     | 初期データとして固定（シードデータ） |
| 複数 admin     | あり（権限変更で昇格・降格も可能）   |
| 自己操作       | 制限なし（自分の権限変更・削除も可） |
| 初期パスワード | admin 側で設定して本人に伝達         |

---

## 6. データ設計（テーブル構成）

### `users` — 認証・権限

| カラム          | 型          | 説明                        |
| --------------- | ----------- | --------------------------- |
| id              | bigint (PK) |                             |
| email           | string      | ログイン用メールアドレス    |
| password_digest | string      | パスワードハッシュ値        |
| role            | string      | `"admin"` または `"member"` |
| created_at      | timestamp   |                             |
| updated_at      | timestamp   |                             |

### `employee_profiles` — 社員情報

| カラム     | 型          | 説明                            |
| ---------- | ----------- | ------------------------------- |
| id         | bigint (PK) |                                 |
| user_id    | bigint (FK) | `users.id` への外部キー（1対1） |
| full_name  | string      | 氏名                            |
| department | string      | 部署                            |
| job_title  | string      | 役職                            |
| phone      | string      | 電話番号                        |
| joined_on  | date        | 入社日                          |
| created_at | timestamp   |                                 |
| updated_at | timestamp   |                                 |

### `attendance_records` — 勤怠

| カラム         | 型          | 説明                                        |
| -------------- | ----------- | ------------------------------------------- |
| id             | bigint (PK) |                                             |
| user_id        | bigint (FK) | `users.id` への外部キー（1対多）            |
| work_date      | date        | 対象日                                      |
| clock_in       | time        | 出勤時刻                                    |
| clock_out      | time        | 退勤時刻                                    |
| worked_minutes | int         | 勤務時間（分）。clock_out - clock_in を保存 |
| created_at     | timestamp   |                                             |
| updated_at     | timestamp   |                                             |

---

## 7. API 一覧

### 認証

| メソッド | パス                 | 説明                         | 権限       |
| -------- | -------------------- | ---------------------------- | ---------- |
| POST     | `/api/auth/login`    | ログイン。トークンを返す     | 全員       |
| POST     | `/api/auth/logout`   | ログアウト。トークンを無効化 | 要ログイン |
| PATCH    | `/api/auth/password` | パスワード変更               | 要ログイン |

### 自分の社員情報

| メソッド | パス      | 説明                         | 権限 |
| -------- | --------- | ---------------------------- | ---- |
| GET      | `/api/me` | 自分のプロフィール情報を取得 | 本人 |
| PATCH    | `/api/me` | 自分のプロフィール情報を更新 | 本人 |

### 勤怠管理

| メソッド | パス                                | 説明                             | 権限 |
| -------- | ----------------------------------- | -------------------------------- | ---- |
| GET      | `/api/me/attendances?month=YYYY-MM` | 指定月の勤怠一覧と月次集計を取得 | 本人 |
| POST     | `/api/me/attendances`               | 勤怠レコードを新規作成           | 本人 |
| PATCH    | `/api/me/attendances/:date`         | 指定日の勤怠レコードを更新       | 本人 |

### 管理者 — アカウント管理

| メソッド | パス                        | 説明                         | 権限  |
| -------- | --------------------------- | ---------------------------- | ----- |
| GET      | `/api/admin/users`          | 全社員アカウント一覧を取得   | admin |
| POST     | `/api/admin/users`          | 新規社員アカウントを作成     | admin |
| PATCH    | `/api/admin/users/:id/role` | 対象ユーザーの権限を変更     | admin |
| DELETE   | `/api/admin/users/:id`      | 対象ユーザーアカウントを削除 | admin |

### 管理者 — 全員勤怠閲覧

| メソッド | パス                                   | 説明                               | 権限  |
| -------- | -------------------------------------- | ---------------------------------- | ----- |
| GET      | `/api/admin/attendances?month=YYYY-MM` | 全社員の指定月の勤怠サマリーを取得 | admin |
